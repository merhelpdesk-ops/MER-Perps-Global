關於 Cloudflare 使用說明：您需要在上傳 GitHub 時點擊 Perps 的 Code，點擊 Create New File，輸入文件名字：.yarnrc.yml，輸入代碼：enableImmutableInstalls: false，即可在 Cloudflare 進行運行。
關於 Vercel 使用說明：您需要在上傳 GitHub 後通過 Vercel 的 Add New 點擊 Project，並且點擊 Import，再點擊 Build and Output Settings，輸入：build/client，即可進行運行。

Regarding Cloudflare usage instructions: You need to upload it to GitHub, click on Perps' Code, then click Create New File, enter the filename: .yarnrc.yml, and input the code: enableImmutableInstalls: false. This will allow it to run on Cloudflare.
Regarding Vercel usage instructions: After uploading to GitHub, you need to go through Vercel's "Add New" → "Project" → "Import", then click on "Build and Output Settings" and enter: `build/client` to run it.

Cloudflare 사용 설명 : 당신은 GitHub 업로드에서 Perps 코드를 클릭해야합니다. 새 파일 만들기를 클릭하여 파일 이름을 입력합니다: .yarnrc.yml, Cloudflare에서 실행하기 위해 enableImmutableInstalls: false 코드를 입력합니다.
Vercel 사용 설명: Github를 업로드한 후 Vercel의 Add New에서 Project를 클릭하고 Import을 클릭하고 Build and Output Settings를 클릭하여 build/client을 입력하면 실행할 수 있습니다.
